- 品牌首页、三个产品入口、英中路由、规范链接、hreflang、sitemap、robots、404。

- OriaTab 九幕演示、主题轮播、Liquid glass、会话强调色、下载入口、更新日志和隐私页面。
- 根据用户反馈移除跨产品统一顶栏；各产品拥有自己的顶栏和页脚，并提供 Oria 系列关联入口。
- OriaTab 顶栏使用不带底框的透明 `logo.svg`。
